## What the organizer does and does not release

The participant kit releases:

- the frozen 50,000-product catalog;
- 200 labeled public development sessions;
- the weak starter Agent;
- the deterministic local evaluator;
- the Agent contract, scoring configuration, specification, and submission rules.

As of the verified official snapshot, the participant-facing product/session datasets
are exactly the 50,000-product catalog and the 200 labeled public sessions; no additional
labeled participant dataset is published.

The official specification states that the organizer keeps 800 additional sessions
private for final evaluation. Our repository/release/history audit found no copy of those
sessions in the participant kit, reachable official history, `data/`, or local
`experiments/`. They are intentionally organizer-only, not a missing or incomplete local
download. The official aggregate scenario proportions are known (`40/40/15/5`), but the
exact rows, product-target identities/distribution, simulator state, and final results
remain unavailable and cannot be verified from participant materials.

The public session rows do not include raw user IDs, review text, timestamps, purchase
history, an intent card, or simulator-policy internals. The evaluator function named
`materialize_hidden_fields` derives local simulator inputs from the released target and
catalog; it does not load an undisclosed private dataset.

## Recheck procedure

From the repository root in PowerShell:

```powershell
python scripts/verify_official_assets.py
git ls-remote upstream refs/heads/main refs/tags/participant-kit
Get-FileHash -Algorithm SHA256 data\releases\catalog.jsonl.gz
(Get-Content data\catalog.jsonl | Measure-Object -Line).Lines
(Get-Content data\public_set.jsonl | Measure-Object -Line).Lines
git diff --exit-code upstream/main -- data\public_set.jsonl
```

The verifier performs the complete offline row/schema/uniqueness/target-membership,
scenario-mix, SHA-256, and Git-blob audit in one command. The remote and release checks
require network access; all local integrity checks and evaluator runs remain offline.
