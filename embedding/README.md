# Catalog embedding experiment

This directory builds normalized dense embeddings for the 50,000-product
catalog using `Qwen/Qwen3-Embedding-0.6B`. Product passages contain only the
title, category, brand, department, and offline-extracted attribute values. Raw
descriptions and extraction evidence are deliberately excluded.

## Dry run

The dry run validates the complete catalog and processed-attribute mapping,
constructs every passage, and prints statistics and examples. It does not import
PyTorch or Sentence Transformers, download the model, or write output files.

```bash
python embedding/build_catalog_embeddings.py --dry-run
```

Use `--limit 1000` to preview the calibration subset that will be used for an
initial timing run.

## GPU setup and calibration

The target machine already provides CUDA-enabled PyTorch in the `python313`
Conda environment. Install only the experiment dependencies:

```bash
conda activate python313
python -m pip install -r embedding/requirements.txt
python embedding/build_catalog_embeddings.py --dry-run
python embedding/build_catalog_embeddings.py \
  --device cuda \
  --batch-size 64 \
  --limit 1000 \
  --output-dir results/embeddings/qwen3_calibration_1000
```

After timing batch size 64, try batch size 128 with a different output directory.
Use the fastest batch size that does not approach the 8 GB VRAM limit.

## Full catalog

```bash
python embedding/build_catalog_embeddings.py \
  --device cuda \
  --batch-size 64
```

The output directory contains:

- `catalog_embeddings.npy`: normalized vectors in catalog order;
- `product_ids.json`: row-to-`parent_asin` mapping;
- `progress.json`: resumable batch progress;
- `manifest.json`: completed-job configuration and input hashes.

Rerunning the same command resumes a partial job. A completed job is returned
without recomputation. Use a new output directory when changing the model,
batch-independent embedding configuration, or product limit.

The default vector storage is float32 (about 195 MiB for 50,000 × 1,024).
`--storage-dtype float16` reduces this to about 98 MiB if desired.

When the retrieval experiment embeds user queries, load the same model and use
`model.encode(queries, prompt_name="query", normalize_embeddings=True)`. The
Qwen model's retrieval instruction belongs on queries only, not on the catalog
passages generated by this script.
